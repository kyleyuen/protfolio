# Personal Portfolio Website

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![Responsive](https://img.shields.io/badge/Responsive-Design-blue) ![Status](https://img.shields.io/badge/Status-Live-success)

A modern, fully responsive personal portfolio website showcasing web development skills through clean HTML and CSS implementation with advanced CSS animations and scroll-based effects.

## 📋 Project Overview

This personal portfolio website demonstrates frontend development expertise through a clean, modern design built entirely with HTML5 and CSS3. The site features advanced CSS animations, scroll-triggered effects using modern CSS properties, and a fully responsive layout that adapts seamlessly across all devices. With no JavaScript dependencies, the portfolio maintains exceptional performance while delivering smooth, engaging user experiences through pure CSS animations and the animation-timeline property.

## 🎯 Purpose

This project was developed to:

- Create a professional online presence to showcase projects and skills
- Master modern CSS3 features including animations, flexbox, and scroll-timeline
- Demonstrate frontend development capabilities through clean, semantic HTML
- Build a fully responsive website without JavaScript dependencies
- Implement scroll-based animations using CSS animation-timeline property
- Design intuitive user interfaces with engaging hover states and transitions
- Develop a lightweight, fast-loading portfolio with optimal performance
- Practice mobile-first responsive design principles and media queries

The portfolio serves as both a showcase of technical abilities and a practical demonstration of frontend development best practices.

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, or Edge)
- Text editor (VS Code, Sublime Text, or similar) for customization
- Git (optional, for cloning)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kyleyuen/Portfolio.git
cd Portfolio
```

2. Open the project:
```bash
# Simply open index.html in your browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

3. View the portfolio:
   - Double-click `index.html` to open in default browser
   - Or right-click and select "Open with" your preferred browser

### Quick Start

```bash

```

## 📖 Usage Guide

### Viewing the Portfolio

1. **Open the website**: Launch `index.html` in any modern browser
2. **Navigate sections**: Scroll through Hero, About, Skills, Projects, and Contact
3. **Interact with elements**: Hover over buttons, project cards, and skill badges
4. **Test responsiveness**: Resize browser window to see responsive behavior

### Customizing Your Portfolio

#### Update Personal Information (index.html)

1. **Hero Section**: Modify name, title, and skills in the hero content
2. **About Section**: Update personal background and professional summary
3. **Skills Section**: Add or remove skill badges in the skills container
4. **Projects Section**: Duplicate `<article class="project">` blocks for new projects
5. **Contact Section**: Update email, LinkedIn, and GitHub links

#### Customize Styling (style.css)

1. **Colors**: Modify CSS variables or color values throughout
2. **Fonts**: Update font-family properties for typography changes
3. **Spacing**: Adjust padding and margin values for layout
4. **Animations**: Modify keyframe animations or transition durations
5. **Responsive Breakpoints**: Update media query breakpoints as needed

#### Adding New Projects

```html
<article class="project">
  <h3>Project Name</h3>
  <p>Project description and technologies used</p>
  <div class="project-links">
    <a href="#" target="_blank">Live Demo</a>
    <a href="#" target="_blank">GitHub Repo</a>
  </div>
</article>
```

### Best Practices

- Keep project descriptions concise and focused
- Use high-quality images for visual elements
- Maintain consistent spacing and alignment
- Test on multiple devices and browsers
- Optimize images for web performance
